Kodi-Repository für Addons und Updates. / Kodi repository for addons and updates.

Installation

Repository-ZIP herunterladen und in Kodi über Add-ons → Paket-Symbol → Aus ZIP-Datei installieren auswählen. Danach Aus Repository installieren → marbra00_repo öffnen.

Download the repository ZIP and select it in Kodi via Add-ons → package icon → Install from ZIP file. Then open Install from repository → marbra00_repo.
