# marbra00_repo

## Deutsch

Unabhängig gepflegtes Kodi-Repository von marbra00 für Addons und Updates.

### Installation

1. Lade die Datei `repository.marbra00_repo-1.0.0.zip` von der [Downloadseite](https://marbra00.github.io/marbra00_repo/) herunter.
2. Öffne in Kodi **Add-ons → Paket-Symbol → Aus ZIP-Datei installieren** und wähle die Datei aus. Falls Kodi die Installation blockiert, kann sie unter **Einstellungen → System → Add-ons → Unbekannte Quellen** freigegeben werden.
3. Öffne **Aus Repository installieren → marbra00_repo**, um die angebotenen Addons auszuwählen.

Das Repository verwendet die Kennung `repository.marbra00_repo` und ist für Kodi 19 oder neuer eingerichtet. Es ist ein inoffizielles Projekt und nicht mit Team Kodi verbunden.

### Updates

Kodi kann neue Versionen der hier angebotenen Addons über dieses Repository beziehen. Ob sie automatisch installiert werden, hängt von deinen Kodi-Einstellungen ab. Für eine manuelle Prüfung öffne das Kontextmenü von `marbra00_repo` und wähle **Auf Aktualisierungen prüfen**.

Die Einstellungen eines Addons gehören weiterhin zum jeweiligen Addon.

## English

*The following text was automatically translated from the German original.*

An independently maintained Kodi repository by marbra00 for addons and updates.

### Installation

1. Download `repository.marbra00_repo-1.0.0.zip` from the [download page](https://marbra00.github.io/marbra00_repo/).
2. In Kodi, open **Add-ons → package icon → Install from ZIP file** and select the file. If Kodi blocks installation, it can be enabled under **Settings → System → Add-ons → Unknown sources**.
3. Open **Install from repository → marbra00_repo** to select the available addons.

The repository uses the ID `repository.marbra00_repo` and is configured for Kodi 19 or newer. It is an unofficial project and is not affiliated with Team Kodi.

### Updates

Kodi can obtain new versions of the available addons from this repository. Automatic installation depends on your Kodi settings. To check manually, open the context menu for `marbra00_repo` and select **Check for updates**.

An addon's settings continue to belong to that addon.
